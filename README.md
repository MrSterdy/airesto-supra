# AIRESTO Supra

[Airesto Supra](https://airesto-supra.tatnet.app) - интерактивная таймлайн-сетка для управления бронированиями и заказами ресторана. Приложение позволяет персоналу видеть загруженность столов по времени и быстро создавать новые брони.

## Что умеет

### Таймлайн-сетка

Основной экран — двумерная сетка, где по горизонтали столы, а по вертикали — время (шаг 15 минут). Бронирования и заказы отображаются цветными блоками с информацией о госте, статусе и количестве человек.

- **Drag-выделение** - зажмите левую кнопку и протяните по столам/времени, чтобы создать бронь
- **Средняя кнопка мыши** - перетаскивание (панорамирование) сетки
- **Масштабирование** - Ctrl+колёсико или клавиши +/− (5 уровней от 0.75× до 1.75×)
- **Индикатор текущего времени** - горизонтальная линия, показывающая «сейчас»
- **Перекрытия** - когда брони на одном столе пересекаются по времени, они автоматически раскладываются рядом друг с другом

### Фильтрация и поиск

- Переключение между доступными днями (с русскими подписями вроде «Сегодня», «Завтра»)
- Фильтр по зонам ресторана (этажи, залы)
- Нечёткий поиск по имени гостя (горячая клавиша ⌘+Л)

### Тема оформления

Светлая и тёмная тема, переключаются одной кнопкой. Выбор сохраняется в localStorage.

## Технические решения

### Виртуализация

Сетка может содержать сотни ячеек (столы × 15-минутки за смену). Чтобы не рендерить всё сразу, используется двумерная виртуализация через **@tanstack/vue-virtual** - в DOM попадают только видимые ячейки.

### Алгоритм раскладки перекрытий

Когда несколько броней на одном столе пересекаются по времени, срабатывает алгоритм кластеризации: пересекающиеся события группируются, внутри группы каждому выделяется своя колонка. Если блок слишком узкий - текст скрывается автоматически.

### Архитектура

Код разделён по фичам, каждая фича — три слоя:
- `domain/` — чистая бизнес-логика и типы (без зависимости от Vue)
- `application/` — composables, связывающие логику с реактивностью
- `presentation/` — Vue-компоненты

Данные загружаются через интерфейс `RestaurantDataSource` (порт). Сейчас подключён мок, но в будущем будет просто заменить на реальный API.

### Производительность

- **Ленивая загрузка** - диалог подтверждения подгружается только при необходимости
- **Ручные чанки** - Vite разделяет бандл на отдельные куски (vue, ui, date, vueuse, data)

### Работа с временными зонами

Ресторан может находиться в любой IANA-зоне.

## Стек

| Что | Чем |
|-----|-----|
| Фреймворк | Vue 3 (Composition API, TypeScript) |
| Сборка | Vite 8 |
| Стили | Tailwind CSS 4 |
| UI-компоненты | shadcn-vue + reka-ui |
| Иконки | Lucide |
| Утилиты | VueUse |
| Виртуализация | @tanstack/vue-virtual |
| Поиск | Fuse.js |
| Даты | date-fns + date-fns-tz |
| Линтинг | ESLint (конфиг @antfu) |

## Запуск

```bash
npm install
npm run dev
```

Продакшн-сборка:

```bash
npm run build
npm run preview
```
